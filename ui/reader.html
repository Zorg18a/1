Конфликт сохранения

Запишите позицию этой вкладки перед обновлением страницы. Проверка не меняет данные; сохранённая позиция может снова измениться. Эта вкладка больше не сохраняет прогресс до перезагрузки.

Клавиши читалки

← / → или P / N — главы; + / − / 0 — масштаб; W / H / O — вписывание; ? — справка. Односимвольные клавиши отключаются в общих настройках.

При горизонтальной прокрутке в исходном размере стрелки управляют прокруткой; для смены главы используйте P / N.
