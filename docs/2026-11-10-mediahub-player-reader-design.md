# MediaHub. Этап 2: плеер, читалка 2.0, «Продолжить» (спецификация дизайна)

Дата: 2026-11-10. Стандарт: WCAG 2.1 AA. Статус: на проверке. Код программы при этом не меняется: это только описание.

## 1. Цель и контекст

Этап 1 перевёл интерфейс на ES-модули и закрыл 22 пункта аудита (см. `2026-11-08-mediahub-a11y-foundation-design.md`). Этап 2 добавляет три вещи на готовой основе:

1. **Страница плеера** для видео и аудио с субтитрами, возобновлением и горячими клавишами.
2. **Читалка 2.0**: клавиши глав, режимы вписывания, масштаб.
3. **Блок «Продолжить»** в Библиотеке.

Что есть сейчас: видео и аудио открываются как сырой файл по `/f/<id>` во встроенном плеере браузера; субтитры yt-dlp сохраняет рядом с файлом в формате `.srt`, но браузер их не подключает (`<track>` понимает только WebVTT); позиция сохраняется только у манги, в таблице `progress(slug, cid, page)`; читалка (`reader.html`) это лента страниц со встроенным скриптом и без клавиш.

Этап 2 затрагивает сервер, БД и три страницы, поэтому он «architectural», в отличие от этапа 1, где серверных таблиц не было.

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Воспроизведение | Страница `/p/<id>` на встроенных элементах `<video controls>` и `<audio controls>`, не свой плеер |
| Позиция | Новая таблица `playpos` в `library.db` |
| Читалка | Лента остаётся; добавляются клавиши и режимы ленты (по ширине, по высоте, исходный), масштаб 50–200 %; постраничного режима нет |
| «Продолжить» | Автовозобновление в плеере плюс блок вверху Библиотеки |

## 3. Вне этапа

Следующая серия и плейлисты, загрузка своих субтитров, оформление субтитров, постраничный режим читалки, миниатюры на шкале времени, статусы «не начато / идёт / завершено» для всей библиотеки (этап 5), расширение браузера.

## 4. Сервер и данные

Все изменения в `app.py` это добавления; существующие маршруты работают как раньше, кроме одной строки (см. «Вход в плеер»). Для всех новых маршрутов действуют те же проверки Host и, для POST, Origin и заголовка `X-MH`.

| Маршрут | Ответ |
|---|---|
| `GET /p/<id>` | Файл `player.html` |
| `GET /api/play/<id>` | `{id, title, kind, src, cover, pos, dur, finished, subs: [{n, lang, label, url}]}`; `src` это `/f/<id>`; 404, если материала нет или он не видео и не аудио |
| `GET /sub/<id>/<n>.vtt` | Субтитры n-го найденного файла в WebVTT; 404, если `n` вне диапазона |
| `POST /api/play/pos` | Тело `{id, pos, dur}`; пишет позицию |
| `POST /api/play/forget` | Тело `{id}`; удаляет строку `playpos`, а для манги строку `progress` |
| `GET /api/continue` | `[{id, kind, title, cover, open, pos, dur, pct, label}]`, до 6 штук, свежие первыми |

**Таблица.** `create table if not exists playpos(item_id integer primary key, pos real not null, dur real not null default 0, updated real not null)`. Для манги в `progress` добавляется столбец `updated real` защищённым `alter table` (как уже сделано для `info`); строки без значения считаются самыми старыми.

**Правила позиции.** Позиция меньше 5 секунд не сохраняется. Материал завершён, если `dur > 0` и `pos >= dur - 10`; завершённое не попадает в «Продолжить» и воспроизводится с нуля. При удалении материала (`/api/delete`) строка `playpos` удаляется там же.

**Субтитры.** Ищутся файлы в папке материала с именем `<имя файла без расширения>.<язык>.srt|vtt` и `<имя>.srt|vtt`; порядок: по языку, затем по имени. Подпись из кода языка (`ru` Русский, `en` English, иначе сам код). Чтение только внутри папки материала. `.srt` преобразуется на лету: заголовок `WEBVTT`, запятая в таймкодах заменяется точкой, BOM убирается. Кодировка: `utf-8-sig`, при ошибке `cp1251`. Файл больше 5 МБ не отдаётся (404). Конвейер скачивания не меняется, поэтому старые загрузки тоже получают субтитры.

**Манга в «Продолжить».** Название главы берётся из `manifest.json`; `pct` это номер главы среди скачанных; материал скрывается, если манифеста нет.

**Вход в плеер.** В `/api/library` для видео и аудио поле `open` становится `/p/<id>` (одна строка в месте, где оно вычисляется); у остальных видов не меняется.

## 5. Плеер

Новые файлы: `player.html`, `js/player/player.js`, `js/player/keys.js`, `css/player.css`. Страница подключает общие токены и режимы отображения (`mh.prefs`, ранний скрипт как в `reader.html`) и `announce` из `js/a11y/announce.js`.

**Разметка.** Шапка: ссылка «Библиотека», `h1` с названием, кнопка «С начала» (видна только при возобновлении). `<main>`: `<video id="m" controls preload="metadata">` или `<audio ...>` с декоративной обложкой (`alt=""`); `<track kind="subtitles">` на каждый файл, без `default`; область `role="alert"` для ошибок.

**Возобновление.** После `loadedmetadata`, если `pos >= 5` и не `finished`, плеер выставляет `currentTime` и озвучивает «Продолжаю с 12:34». «С начала» перематывает на ноль и озвучивает «С начала».

**Сохранение.** Раз в 5 секунд во время воспроизведения (только если позиция изменилась не меньше чем на секунду), при паузе, конце и `pagehide`; запрос `fetch` с `keepalive: true` и заголовком `X-MH`.

**Горячие клавиши.** Работают при `mh.prefs.keys = true`, не в полях ввода и не при нажатых Ctrl, Alt, Meta. Встроенные клавиши элемента (пробел, стрелки при фокусе на плеере) не отключаются.

| Клавиша | Действие | Озвучивание |
|---|---|---|
| `k` | Пауза и воспроизведение | «Пауза» / «Воспроизведение» |
| `j` / `l` | Назад и вперёд на 10 секунд | «Назад на 10 секунд, 1:13» |
| `[` / `]` | Скорость на 0.25 меньше и больше, от 0.5 до 2 | «Скорость 1.25» |
| `c` | Субтитры по кругу: выкл, затем каждая дорожка | «Субтитры: Русский» / «Субтитры выключены» |
| `m` | Звук | «Звук выключен» / «Звук включён» |
| `f` | Полный экран (только видео) | «Полный экран» |
| `?` | Справка по клавишам (`<dialog>`) | |

**Ошибки.** При событии `error` у элемента показывается сообщение «Не удалось воспроизвести файл. Возможно, браузер не поддерживает его формат» с ссылкой «Открыть файл напрямую» (`/f/<id>`); если материала нет, сообщение «Материал не найден».

## 6. Читалка 2.0

Новые файлы: `js/reader/reader.js` (встроенный скрипт `reader.html` переезжает сюда без изменения логики), `js/reader/modes.js`; `reader.html` остаётся каркасом.

**`modes.js` (чистые функции).** `FITS = ['width', 'height', 'orig']`; `clampZoom(z)` ограничивает 50–200 и округляет до шага 10; `loadReaderPrefs()` и `saveReaderPrefs(p)` работают с `localStorage['mh.reader'] = {fit, zoom}` (по умолчанию `width`, 100; недоступное хранилище и испорченный JSON не ломают страницу); `imageStyle(fit, zoom)` возвращает значения CSS-переменных для страниц.

**Режимы.** «По ширине»: страница занимает ширину колонки (сейчас до 900 px) умноженную на масштаб. «По высоте»: страница по высоте окна за вычетом шапки, масштаб умножает высоту. «Исходный размер»: естественный размер умноженный на масштаб, горизонтальная прокрутка внутри контейнера.

**Управление в шапке.** Группа радио-кнопок «Вписывание» (`role=radiogroup`, стрелки через `initRadios`), кнопки «Уменьшить масштаб» и «Увеличить масштаб», значение «120 %» в области `aria-live=polite`.

**Клавиши** (при `keys = true`; прокрутка, пробел, PageUp и PageDown не перехватываются):

| Клавиша | Действие | Озвучивание |
|---|---|---|
| `←` / `→` или `p` / `n` | Предыдущая и следующая глава | «Глава 3 из 12» |
| `+` / `-` / `0` | Масштаб больше, меньше, 100 % | «Масштаб 120 %» |
| `w` / `h` / `o` | По ширине, по высоте, исходный | «По ширине» и т. д. |
| `?` | Справка (`<dialog>`) | |

В режиме «Исходный размер» при наличии горизонтальной прокрутки стрелки отдаются браузеру; главы переключаются клавишами `p` и `n`.

**Смена главы.** Страницы главы загружаются как раньше; фокус переходит на `h2` «Глава N» (`tabindex=-1`), озвучивается «Глава 3 из 12»; сохранение страницы через `/api/progress` не меняется.

## 7. Блок «Продолжить»

Новый файл `js/views/continue.js`: `loadContinue(): Promise<void>` запрашивает `/api/continue`; `continueHtml(items: Item[]): string` возвращает разметку. Вызывается из `loadLibrary()`; блок показывается только если элементы есть, поле поиска пусто и фильтр «Все».

Разметка: `<section aria-labelledby="contH">` с `h2` «Продолжить» и списком `<ul>`; элемент списка это карточка прежнего вида (`<article class="c">`, ссылка `.cv` на `/p/<id>` или `/m/<id>`, `h3`, подпись «осталось 12 мин» или «глава 3, стр. 14») с `role=progressbar` и подписью «Просмотрено» и кнопкой «Убрать из «Продолжить»: <название>». После удаления озвучивается «Убрано из «Продолжить»», фокус идёт на следующую карточку или на заголовок раздела. Карточки входят в навигацию `j`/`k`.

## 9. Тесты и приёмка

Папка `tests/`, как в этапе 1.

**Сервер без браузера** (`tests/test_play_api.py`): `/api/play` (поля, `subs`), `/sub/<id>/<n>.vtt` (заголовок `WEBVTT`, точка в таймкодах, кодировки `utf-8-sig` и `cp1251`, `n` вне диапазона, лимит 5 МБ, имя вне папки не открывается), запись и чтение позиции, правило завершения, `forget`, чистка `playpos` при удалении, проверка Host. Тестовые файлы создаёт фикстура `server.add_media(...)`: короткий WAV из модуля `wave` (ffmpeg не нужен; Chromium проигрывает его и в `<video>`) и файлы субтитров рядом.

**Плеер** (`tests/test_player.py`): возобновление и озвучивание, «С начала», клавиши `k j l [ ] c m`, выключение клавиш переключателем, сохранение позиции, сообщение об ошибке на битом файле.

**Читалка** (`tests/test_reader2.py`): режимы и масштаб меняют размеры страниц, клавиши глав и их озвучивание, стрелки в режиме «Исходный размер», `mh.reader`, чистые функции `modes.js`. Данные манги подставляются через `page.route`.

**«Продолжить»** (`tests/test_continue.py`): блок появляется после записи позиции, удаление с переносом фокуса, скрытие при поиске.

**Сквозные проверки** этапа 1 (`test_rules`, `test_matrix`, `test_keyboard_walk`) распространяются на `/p/<id>` и `/m/<id>`: имена элементов, структура, контраст текста в 4 сочетаниях, 320 px, обход клавиатурой, axe при наличии `tests/vendor/axe.min.js`.

**Готовность этапа 2:** все новые тесты и 175 прежних проходят; ручной чек-лист `docs/a11y-manual-stage2.md` (5 сценариев в NVDA с Firefox и Яндекс Браузером: возобновление видео, меню субтитров, озвучивание клавиш плеера, режимы читалки, «Продолжить») подписан.

## 10. Порядок и риски

Порядок: сервер и таблица, затем плеер, читалка, «Продолжить», затем сквозные проверки. После каждого шага запускается весь набор тестов.

Риски:
- браузер не проигрывает `mkv` и `avi`: для этого есть сообщение и ссылка на сырой файл;
- субтитры в старых кодировках и огромные файлы: перебор `utf-8-sig` и `cp1251`, лимит 5 МБ;
- запись позиции при закрытии вкладки не гарантирована даже с `keepalive`; допустимая потеря это последние секунды;
- замена `open` для видео и аудио должна затрагивать только эти виды: проверяется тестом;
- перенос встроенного скрипта читалки в модуль может сломать загрузку главы: логику переносим без изменений и покрываем тестом с подставленными данными манги.
