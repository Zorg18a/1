# Состояние проекта — 2026-11-08

## Исходное состояние

В `MediaHub.zip`: MediaHub v2 — локальный Python HTTP-сервер, HTML-интерфейс и читалка,
загрузчик через yt-dlp/Playwright, GameSweep, парсер карточек игр, расширения Chromium и
Firefox, инструкции и вложенный zip расширения. В распакованном репозитории дополнительно
была SQLite-база с 782 записями и кеш Python; сама база в архив не входила.

## Сделано

- Сохранён существующий функционал как совместимый `legacy/`, логика карточек перенесена в
  `core/`, начальный доступ к SQLite — в `storage/`, страницы — в `ui/`.
- Создана точка входа, зависимости, игнорирование личных данных, инструкции, документация и CI.
  Старая база остаётся локально в `MediaHub/library.db`; перенос — вручную по README.
- Архивы, база и кеш удалены из отслеживаемого дерева новой ветки, но остаются в прежней
  истории Git и основной ветке до слияния; удаление из истории здесь не выполнялось.
- Созданы unit/integration-тесты; в Linux Python 3.11: 8 тестов успешно, compileall успешно,
  GameSweep selftest 73/73; `node --check` для HTML-скриптов и расширений успешно.
  HTTP-тесты используют временную базу. Внешние сайты, скачивание и реальные расширения не тестировались.
- Actions сборка PyInstaller `--onedir` прошла на Windows (run 42492149106). Скачать
  артефакт в этой среде не удалось: GitHub перенаправляет на недоступный blob-хост.
  Добавлен автоматический Windows smoke-тест EXE: UI, API, ресурсы, Host и GameSweep.
  Ручная проверка Windows и реальных загрузок всё ещё необходима.
- Копия исходной базы проверена через HTTP: все 782 записи доступны, integrity_check = ok;
  оригинал не изменялся. Пути к пользовательским файлам на Windows ещё не проверены.
  Добавлен интеграционный тест миграции синтетической старой базы. Сейчас 9 тестов проходят.
  Smoke-сценарий дополнительно прошёл на запуске исходного кода в Linux.
- Локальная Linux-сборка PyInstaller по-прежнему невозможна без `libpython3.11.so`.

## Решения и ограничения

- Интерфейс — локальная веб-страница, а не нативное окно. Host/Origin проверки сохранены.
- Целевая архитектура и лимит 200 строк ещё не достигнуты: два больших файла `legacy/`,
  `ui/index.html` и два background.js — зафиксированные исключения. Legacy по-прежнему
  смешивает HTTP, логику и данные; единый формат ошибок не применяется ко всем старым маршрутам.
  Не обещаем, что функции вне проверенных сценариев не сломаны.
- Зависимости намеренно не зафиксированы версиями, как в оригинале; воспроизводимость ограничена.
