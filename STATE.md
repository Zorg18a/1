## Архитектурная доработка — этап 1

- Фактический сервер — стандартный `ThreadingHTTPServer`, не Flask; предыдущий UI
  монолитный, существующий мост расширения поддерживает подключение и карточки игр.
- Добавлены нативные ES-модули для темы, размера, контраста и клавиш (localStorage),
  журнала сессии, тостов на 8 секунд и уведомлений о завершении загрузок. Сервер выдаёт
  только разрешённые файлы UI; расширения и интерфейс GameSweep пока не темизируются.
- Локально: 29 Python-тестов и 4 Node-теста, синтаксис JS/Python; интеграция новых
  модулей проверена в синтетическом DOM (jsdom), не в реальном браузере. Windows Actions
  run 42503292152: тесты, сборка и HTTP smoke EXE прошли для коммита 4eedcae.
- Существующие функции обнаружены: извлечение игровых данных из страницы через
  расширение, жанры, сравнение версий, сортировка и кэш обложек в папке загрузок.
  Дополнения для кнопки «в один клик», пользовательских тегов и сортировки ещё не сделаны.
- Умный патчер и мигратор сохранений НЕ реализованы: сначала необходимы безопасный
  дизайн, подтверждение и тесты на копиях, защита от вредоносных архивов и откат.

## Архитектурная доработка — этап 3: теги и сортировка

- Пользовательские теги валидируются в `core/game_tags.py` и атомарно сохраняются в
  отдельной таблице SQLite; существующие метаданные сайта не перезаписываются. При
  явном удалении карточки теги удаляются триггером. Повторное сканирование сохраняет
  карточку без папки, если у неё есть теги или заметка; добавлена защита от гонки
  сохранения тегов с удалением карточки при сканировании.
- В карточке — форма редактирования с обратной связью, в каталоге — общий фильтр по
  жанрам, пользовательским тегам и движку, поиск и фильтр по размерам. Сортировка и
  размерный фильтр сохраняются в localStorage; обновления идут первыми при любой
  сортировке. Размер берётся из существующего сканера и относится к выбранной версии;
  0 и недоступный размер пока не различаются, ошибки отдельных файлов сканер пропускает.
- Локально прошли 34 Python-теста, 15 Node-тестов, проверка синтаксиса модулей и HTML,
  GameSweep selftest 73/73 и HTTP smoke исходного кода. На синтетическом DOM (jsdom)
  проверены открытие карточки, сохранение тегов, экранирование, фокус и фильтры; это
  не заменяет проверку реального браузера. Windows Actions run 42514374993: тесты,
  сборка EXE, smoke и артефакт прошли для 18f88e3; ручной тест Windows не выполнен.
  Данные тестов — временные.
- Кэш обложек в указанной пользователем папке и Smart Update с безопасной миграцией
  сохранений всё ещё не реализованы. Не изменять файлы игр до отдельного безопасного дизайна.

## Решения и ограничения

- Интерфейс — локальная веб-страница, а не нативное окно. Host/Origin проверки сохранены.
- Целевая архитектура и лимит 200 строк ещё не достигнуты: два больших файла `legacy/`,
  `ui/index.html` и два background.js — зафиксированные исключения. Legacy по-прежнему
  смешивает HTTP, логику и данные; единый формат ошибок не применяется ко всем старым маршрутам.
  Не обещаем, что функции вне проверенных сценариев не сломаны.
- Зависимости намеренно не зафиксированы версиями, как в оригинале; воспроизводимость ограничена.
