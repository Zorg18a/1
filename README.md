# MediaHub

Локальное Windows-приложение с интерфейсом в браузере: загрузка видео, аудио, сайтов и
манги; библиотека и читалка; работа с вкладками через расширение; каталог игр и GameSweep.
См. также историческое описание возможностей в `legacy/README-original.md` (его пути устарели).

## Запуск исходного кода (Windows)

Установите Python 3.11 или новее, затем в корне проекта выполните:

```bat
py -3 -m pip install -r requirements.txt
py -3 app.py
```

Либо запустите `start.bat`. Откроется http://127.0.0.1:8765; оставьте консоль работающей.
Для склейки видео и обработки аудио нужен ffmpeg/ffprobe в PATH или в папке `ffmpeg` рядом
с `app.py`. Некоторые сайты требуют deno, Playwright и установленного браузера (в зависимости
от настройки). Для отдельного Chromium выполните `py -3 -m playwright install chromium` и
выберите Chromium в настройках. Загрузка с конкретных сайтов зависит от их доступности и правил.

Расширения: Chrome/Edge — загрузите распакованную папку `extension`; Firefox — временно через
`about:debugging` файл `extension-firefox/manifest.json`. Для постоянной установки Firefox
архивируйте содержимое этой папки и подпишите его в Mozilla. Подтвердите подключение в MediaHub.
На открытой HTTPS-теме `f95zone.to/threads/...` кнопка «Добавить текущую игру» ставит карточку
в очередь без закрытия вкладки; результат или ошибка видны в «Загрузках». При первом подключении
сначала разрешите расширение в MediaHub и нажмите кнопку снова. Если приложение недоступно,
повторите вручную: автоматической отложенной отправки для этой кнопки нет. Расширение читает
HTML темы в браузере пользователя, чтобы извлечь название, версию, ссылку и адрес обложки;
вход на сайт и доступность страницы необходимы. Другие сайты этой кнопкой пока не поддерживаются.

## Сохранение старых данных

**До переключения ветки или обновления сохраните копию старой папки `MediaHub` вне репозитория**:
база ранее отслеживалась Git и при обновлении может быть удалена из рабочего дерева. При
выключенном приложении скопируйте `MediaHub/library.db` в корень рядом с `app.py` (или рядом
с `MediaHub.exe` в распакованной сборке); при необходимости так же перенесите `settings.json`,
`ext.json`, `archive_*.txt`, `browser_profile` и папку `ffmpeg`. Не перезаписывайте существующую
базу без резервной копии. Старые пути к скачанным файлам должны быть доступны на той же машине.
`ext.json` содержит секреты расширений — не публикуйте его. В исходной версии репозитория база находилась в `MediaHub/library.db`; после обновления
она может отсутствовать, поэтому заранее сохраните её копию. Данные создаются автоматически,
если их не перенести. `MEDIAHUB_DATA_DIR` при необходимости задаёт альтернативную папку данных.

## Копия базы библиотеки

В «Настройки → Резервная копия базы» нажмите **«Скачать копию базы»**. MediaHub
сформирует снимок SQLite в памяти и проверит его целостность; браузер предложит файл
`mediahub-library-….db`. Проверьте, что загрузка завершилась, и сохраните копию в
безопасном месте: база может содержать личные ссылки, названия и заметки.

Копия содержит только базу (до 64 МиБ). Скачанные файлы, сохранения игр, настройки,
данные расширений и позиция плеера из браузера в неё не входят. Храните их отдельно.
При большой базе, занятой транзакции или ошибке проверки скачивание не выполняется;
создание копии временно блокирует другие операции с базой. Чтобы проверить ранее
скачанную копию, выберите файл в том же разделе и нажмите **«Проверить копию»**.
Проверяются целостность SQLite и минимальная структура; результат не подтверждает
совместимость с любой версией приложения или наличие медиафайлов. Рабочая база при
проверке не заменяется. Поддерживаются автономные файлы SQLite до 64 МиБ, без WAL.
Восстановление из интерфейса пока не реализовано. Перед обновлением приложения всё равно сделайте внешнюю копию
данных при выключенном приложении, как описано выше.

## Доступность и уведомления

В «Настройки → Отображение и доступность» выбираются тема, размер интерфейса,
контраст и включение горячих клавиш. Выбор хранится в localStorage текущего браузера.
Справка по клавишам и журнал уведомлений доступны в боковой панели: нажмите `G`,
затем `L`, `I`, `D`, `G` или `S` для перехода в соответствующий раздел. Журнал
хранится только до закрытия/перезагрузки страницы, тосты исчезают через 8 секунд.
При блокировке localStorage настройки работают до перезагрузки, но не сохраняются.

В читалке можно выбрать вписывание по ширине, высоте или исходный размер и масштаб
50–200 %. Настройки читалки сохраняются в localStorage браузера. Для клавиатуры доступны
стрелки или P/N для смены главы, +/−/0 для масштаба, W/H/O для вписывания и ? для
справки. В исходном размере при горизонтальной прокрутке стрелки прокручивают изображение;
для смены главы используйте P/N. Горячие клавиши отключаются общим переключателем.
Если идентификатор записи библиотеки не совпадает с манифестом манги, читалка сообщает
об этом и позволяет читать без сохранения позиции; прежние записи не меняются. Если
идентификатор записи или сохранённая позиция изменились во время чтения, сохранение
останавливается. Можно увидеть позицию этой вкладки и проверить сохранённую, а затем
явно подтвердить замену или записать нужную позицию до обновления читалки. Если позиция
снова изменилась, запись отклоняется и нужна новая проверка. После подтверждённого
сохранения обычное автосохранение продолжается. Проверка не обнаруживает изменения,
после которых позиция вернулась к прежним значениям; старые клиенты могут писать
без такой проверки. Не удаляйте записи для исправления без резервной копии.

На карточке доступного видео или аудио в библиотеке есть ссылка «Предпросмотр плеера»
(`/p/<id>`): на странице доступны стандартные элементы браузера и выбор найденных
субтитров. Выбор сохраняется в localStorage для каждого материала, если браузер разрешает
хранение; при одинаковых подписях дорожек выбор автоматически не восстанавливается.
Отображение субтитров, особенно для аудио, зависит от браузера. Основная ссылка на обложке
по-прежнему открывает файл напрямую. Предварительный плеер сохраняет позицию только в
localStorage текущего браузера: после перезагрузки она восстанавливается без автозапуска,
кнопка «С начала» её сбрасывает. Запись делается при перемотке, паузе и периодически во
время воспроизведения; очистка хранилища, закрытие браузера до записи или другие вкладки
могут привести к потере или перезаписи позиции. В другом браузере и при прямом открытии
файла позиция недоступна. При блокировке хранилища плеер сообщает об ошибке. Привязка к
файлу использует его метаданные и не гарантирует распознавание каждой замены. Позиция
не записывается в базу и не участвует в бэкапе базы. Субтитры имеют ограничения путей и
файловых систем, описанные в `docs/player-reader-plan.md`.

## Игровая библиотека

В карточке игры можно добавить до 20 собственных тегов (через запятую, каждый до
40 символов). Они хранятся в базе отдельно от жанров сайта. Фильтр «Жанры и теги»
также включает движок; выбранные метки объединяются по принципу «и». Поиск учитывает
название, разработчика, жанры и теги. После сохранения тегов метки обновляются сразу.
При сканировании существующие карточки не удаляются только потому, что игра не попала
в результат: причина может быть в структуре папок или недоступной категории. Если файл
или папка отсутствует, игра показывается как не скачанная; ненужную карточку можно удалить
явно вместе с её тегами. Перед переносом или обновлением базы сделайте копию.

### Папки и подпапки игр

В «Настройки → Игры» укажите корневую папку и выберите **структуру папок игр**:

- `Корень → игра`: папки игр находятся прямо в выбранном корне.
- `Корень → категория → игра`: например, `Игры/Категория/College Traits/`.
- `Корень → категория → подпапка → игра`: например, `Игры/Категория/Подпапка/College Traits/`.
- `Авто` раскрывает только категории с именами вроде `new1`, `part2`, `batch3`; другие
  папки в корне считаются играми.

Выбор задаёт уровень, на котором папка целиком считается игрой. Автоматически определить,
где категория, а где внутренняя папка игры, нельзя: при неверной структуре можно получить
неправильные результаты. Архивы распознаются на пройденных уровнях; символические ссылки
и точки повторной обработки при перечислении пропускаются. Это не защита от внешней
подмены путей. Если библиотека смешанной структуры, выберите подходящий подкорень или
проверьте результаты вручную. После изменения структуры для текущего сканирования
откройте «Игры → Версии», выберите там такую же структуру и нажмите «Сканировать»;
при следующем запуске приложение использует настройку автоматически. Перед отправкой
версий в Корзину всегда проверяйте полные пути и найденные сохранения.

Размер определяется при сканировании GameSweep как сумма размеров доступных файлов
выбранной версии; 0 байт и неизвестный размер объединены в одном фильтре. У нескольких
версий размер относится к выбранной версии, а не ко всем версиям вместе. Сортировка и
размерный фильтр сохраняются в localStorage браузера. Игры с обнаруженным обновлением
всегда идут первыми, затем применяется выбранная сортировка. Поддерживаются даты выхода
в форматах, распознаваемых браузером, включая `ДД.ММ.ГГГГ`; неизвестные даты идут последними.

### Обложки игр

В настройке «Папка загрузок» выберите папку MediaHub: новые игровые обложки
сохраняются в её подпапку `covers` (по умолчанию `Downloads/MediaHub/covers`).
При сканировании установленной игры без доступной обложки приложение ищет файлы
`cover`, `folder` или `poster` с расширениями JPG, JPEG, PNG, WebP, GIF или AVIF
непосредственно в папке выбранной версии и сохраняет копию. Вложенные папки,
произвольные изображения и содержимое игровых архивов не просматриваются.

Старые доступные обложки остаются на прежнем пути; при смене папки загрузок они
автоматически не переносятся. Новые файлы получают уникальные имена и не перезаписывают
старые. Изображения ограничены 8 000 000 байтами и проверяются по сигнатуре, не полным
декодированием. Если обложка недоступна, остаётся заглушка; ошибки кэша записываются
в журнал приложения. Исходные файлы игры и старый кэш не удаляются. Автоматической
очистки неиспользуемых копий пока нет.

### Поиск скачанного обновления

Откройте карточку установленной игры. Кнопка «Обновить» открывает тему игры, если она
известна; выберите ссылку и скачайте архив вручную. При открытой карточке MediaHub
создаёт папку `Incoming_Downloads` внутри папки загрузок и показывает её путь. Сохраните
архив туда: поиск повторяется каждые 15 секунд, пока карточка открыта и вкладка видима;
его также можно запустить кнопкой «Обновить поиск».

Показываются только возможные совпадения по нормализованному имени для файлов ZIP, 7z,
RAR, TAR, TAR.GZ и TGZ непосредственно в этой папке; вложенные папки и ссылки не
просматриваются. Результат может ошибаться или не найти архив с иным именем. За один
поиск просматривается не более 5000 записей и выводится до 50 совпадений, с предупреждением
об ограничении. Содержимое архива и завершённость скачивания **не проверяются**. Папка
входящих загрузок и папка игр не должны пересекаться. Имя `Incoming_Downloads` зарезервировано:
GameSweep пропускает такие подпапки при сканировании; не выбирайте Incoming_Downloads
самой корневой папкой GameSweep.

Для совпавшего ZIP доступна кнопка «Проверить метаданные ZIP»: приложение без распаковки
проверяет центральный каталог, ограничения размеров, имена и некоторые типы записей.
ZIP64, многотомные, зашифрованные, самораспаковывающиеся архивы и неподдерживаемые методы
сжатия предварительная проверка отклоняет; RAR/7z/TAR пока не проверяются. Максимум —
5000 элементов и 4 МиБ центрального каталога. Обнаруженное изменение атрибутов файла
требует обновить поиск. При проверке метаданных содержимое, локальные заголовки и CRC
не проверяются; атрибуты не являются криптографическим отпечатком содержимого.

Отдельная кнопка «Проверить данные и CRC ZIP» повторно проверяет метаданные, локальные
заголовки и CRC данных stored/deflate, распаковывая только в ограниченный буфер памяти.
Лимиты: 128 МиБ сжатых и 256 МиБ распакованных данных, 4 МиБ локальных метаданных,
не более одной проверки данных одновременно и ориентировочно 30 секунд между операциями
чтения. Зависшее чтение, например с сетевого диска, таймер прервать не может. Некоторые
нестандартные ZIP отклоняются. Даже успешная проверка CRC **не подтверждает безопасность,
подлинность, принадлежность игре или завершение скачивания** и не гарантирует защиту от
подмены файла; перед любой будущей установкой необходимы повторные проверки.

Кнопка «Найти возможные сохранения» отдельно просматривает имена внутри выбранной
папки игры из текущего корня библиотеки. Ищутся известные имена папок сохранений и
расширения/имена файлов; содержимое файлов не читается, найденная папка показывается
целиком без обхода её содержимого. Это лишь подсказки: AppData, облачные и другие
неизвестные расположения не проверяются, а отсутствие совпадений не означает отсутствие
сохранений. Ссылки и точки повторной обработки пропускаются; при обнаружении пропусков,
ошибок или лимитов показывается предупреждение о неполном поиске.

Лимиты поиска: 5000 элементов, 100 подсказок, глубина обхода каталогов 8 (их элементы
могут находиться на уровне 9), одна операция одновременно,
ориентировочно 10 секунд между файловыми операциями. Блокирующее чтение, например на
сетевом диске, таймер не прерывает. Атрибуты путей проверяются, но гонки с подменой
папок полностью не исключены. Результат не является планом установки или резервной копией.

Отдельная кнопка «Посмотреть состав возможных сохранений» повторяет поиск и показывает
имена и размеры отдельных найденных файлов и файлов внутри найденных папок сохранений.
Это могут быть не только сохранения. Содержимое файлов не читается; размеры — сведения
файловой системы, сумма учитывает каждый найденный путь, в том числе жёсткие ссылки.
Дополнительные пределы: 5000 элементов, 200 файлов, глубина обхода найденной папки 8,
1024 байта на относительный путь и ориентировочно 10 секунд между операциями. Первичный
поиск имеет отдельные лимиты; пропуски и их достижение показываются как неполный просмотр.
Зависшее чтение с сетевого диска не прерывается. AppData и облачные сохранения не ищутся,
а ошибки и гонки подмены полностью не исключены. Список может устареть и не пригоден как
безопасный манифест копирования или подтверждение сохранности данных.

Для выбранного ZIP кнопка «Сопоставить пути сохранений с ZIP» заново ищет подсказки в
папке игры и сравнивает их имена с центральным каталогом архива. Она показывает совпадение
пути, общую папку, конфликт типов или файл в пути. Сравнение приблизительное: регистр и
Unicode нормализуются, а пути сравниваются от корней игры и ZIP, без поиска возможной
папки-обёртки. Содержимое папок сохранений, AppData и облако не проверяются. Отсутствие
совпадений не исключает конфликты; локальные заголовки, данные и CRC на этом шаге не
проверяются. Действуют ограничения поиска сохранений и проверки метаданных ZIP; результаты
могут устареть или оказаться неполными и не являются планом установки.

Установки, распаковки, бэкапа и переноса сохранений нет; файлы игр и архивы не
изменяются. План безопасной реализации — `docs/smart-update-design.md`.

## Windows-сборка

После push откройте GitHub Actions → **Build Windows executable** → успешный запуск →
**Artifacts → MediaHub-Windows**. Распакуйте архив целиком в доступную для записи папку и
запустите `MediaHub.exe`; папка `_internal` обязательна. Это сборка `--onedir`, не одиночный
самодостаточный exe. FFmpeg, deno и браузеры Playwright не включены; установите их отдельно,
если они нужны. Настройки, база и профили создаются рядом с exe. Не запускайте из Program Files
без прав записи. Адреса расширений показывает вкладка настроек; при переносе сборки может
потребоваться повторная установка расширения.

## Проверка

```bat
py -3 -m unittest discover -s tests -v
py -3 -m compileall -q app.py core storage ui legacy tests
py -3 legacy/gamesweep.py --selftest
node --test tests/test_ui.mjs tests/test_quick_game.mjs tests/test_game_library.mjs tests/test_update_preview.mjs
```

Тесты используют временную базу и не скачивают контент из интернета. Windows workflow также запускает собранный EXE и проверяет ресурсы и локальное API.
Полная проверка загрузок,
расширений и Windows требует ручного тестирования. Память проекта: `AGENTS.md`, `MAP.md`, `STATE.md`.
