# MediaHub

Локальное Windows-приложение с интерфейсом в браузере: загрузка видео, аудио, сайтов и
манги; библиотека и читалка; работа с вкладками через расширение; каталог игр и GameSweep.
См. также историческое описание возможностей в `legacy/README-original.md` (его пути устарели).

## Запуск исходного кода (Windows)

Установите Python 3.11 или новее, затем в корне проекта выполните:

```bat
py -3 -m pip install -r requirements.txt
py -3 app.py
```

Либо запустите `start.bat`. Откроется http://127.0.0.1:8765; оставьте консоль работающей.
Для склейки видео и обработки аудио нужен ffmpeg/ffprobe в PATH или в папке `ffmpeg` рядом
с `app.py`. Некоторые сайты требуют deno, Playwright и установленного браузера (в зависимости
от настройки). Для отдельного Chromium выполните `py -3 -m playwright install chromium` и
выберите Chromium в настройках. Загрузка с конкретных сайтов зависит от их доступности и правил.

Расширения: Chrome/Edge — загрузите распакованную папку `extension`; Firefox — временно через
`about:debugging` файл `extension-firefox/manifest.json`. Для постоянной установки Firefox
архивируйте содержимое этой папки и подпишите его в Mozilla. Подтвердите подключение в MediaHub.

## Сохранение старых данных

**До переключения ветки или обновления сохраните копию старой папки `MediaHub` вне репозитория**:
база ранее отслеживалась Git и при обновлении может быть удалена из рабочего дерева. При
выключенном приложении скопируйте `MediaHub/library.db` в корень рядом с `app.py` (или рядом
с `MediaHub.exe` в распакованной сборке); при необходимости так же перенесите `settings.json`,
`ext.json`, `archive_*.txt`, `browser_profile` и папку `ffmpeg`. Не перезаписывайте существующую
базу без резервной копии. Старые пути к скачанным файлам должны быть доступны на той же машине.
`ext.json` содержит секреты расширений — не публикуйте его. В исходной версии репозитория база находилась в `MediaHub/library.db`; после обновления
она может отсутствовать, поэтому заранее сохраните её копию. Данные создаются автоматически,
если их не перенести. `MEDIAHUB_DATA_DIR` при необходимости задаёт альтернативную папку данных.

## Доступность и уведомления

В «Настройки → Отображение и доступность» выбираются тема, размер интерфейса,
контраст и включение горячих клавиш. Выбор хранится в localStorage текущего браузера.
Справка по клавишам и журнал уведомлений доступны в боковой панели: нажмите `G`,
затем `L`, `I`, `D`, `G` или `S` для перехода в соответствующий раздел. Журнал
хранится только до закрытия/перезагрузки страницы, тосты исчезают через 8 секунд.
При блокировке localStorage настройки работают до перезагрузки, но не сохраняются.

## Windows-сборка

После push откройте GitHub Actions → **Build Windows executable** → успешный запуск →
**Artifacts → MediaHub-Windows**. Распакуйте архив целиком в доступную для записи папку и
запустите `MediaHub.exe`; папка `_internal` обязательна. Это сборка `--onedir`, не одиночный
самодостаточный exe. FFmpeg, deno и браузеры Playwright не включены; установите их отдельно,
если они нужны. Настройки, база и профили создаются рядом с exe. Не запускайте из Program Files
без прав записи. Адреса расширений показывает вкладка настроек; при переносе сборки может
потребоваться повторная установка расширения.

## Проверка

```bat
py -3 -m unittest discover -s tests -v
py -3 -m compileall -q app.py core storage ui legacy tests
py -3 legacy/gamesweep.py --selftest
node --test tests/test_ui.mjs
```

Тесты используют временную базу и не скачивают контент из интернета. Windows workflow также запускает собранный EXE и проверяет ресурсы и локальное API.
Полная проверка загрузок,
расширений и Windows требует ручного тестирования. Память проекта: `AGENTS.md`, `MAP.md`, `STATE.md`.
