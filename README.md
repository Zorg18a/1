# MediaHub

Локальное Windows-приложение с интерфейсом в браузере: загрузка видео, аудио, сайтов и
манги; библиотека и читалка; работа с вкладками через расширение; каталог игр и GameSweep.
См. также историческое описание возможностей в `legacy/README-original.md` (его пути устарели).

## Запуск исходного кода (Windows)

Установите Python 3.11 или новее, затем в корне проекта выполните:

```bat
py -3 -m pip install -r requirements.txt
py -3 app.py
```

Либо запустите `start.bat`. Откроется http://127.0.0.1:8765; оставьте консоль работающей.
Для склейки видео и обработки аудио нужен ffmpeg/ffprobe в PATH или в папке `ffmpeg` рядом
с `app.py`. Некоторые сайты требуют deno, Playwright и установленного браузера (в зависимости
от настройки). Для отдельного Chromium выполните `py -3 -m playwright install chromium` и
выберите Chromium в настройках. Загрузка с конкретных сайтов зависит от их доступности и правил.

Расширения: Chrome/Edge — загрузите распакованную папку `extension`; Firefox — временно через
`about:debugging` файл `extension-firefox/manifest.json`. Для постоянной установки Firefox
архивируйте содержимое этой папки и подпишите его в Mozilla. Подтвердите подключение в MediaHub.
На открытой HTTPS-теме `f95zone.to/threads/...` кнопка «Добавить текущую игру» ставит карточку
в очередь без закрытия вкладки; результат или ошибка видны в «Загрузках». При первом подключении
сначала разрешите расширение в MediaHub и нажмите кнопку снова. Если приложение недоступно,
повторите вручную: автоматической отложенной отправки для этой кнопки нет. Расширение читает
HTML темы в браузере пользователя, чтобы извлечь название, версию, ссылку и адрес обложки;
вход на сайт и доступность страницы необходимы. Другие сайты этой кнопкой пока не поддерживаются.

## Сохранение старых данных

**До переключения ветки или обновления сохраните копию старой папки `MediaHub` вне репозитория**:
база ранее отслеживалась Git и при обновлении может быть удалена из рабочего дерева. При
выключенном приложении скопируйте `MediaHub/library.db` в корень рядом с `app.py` (или рядом
с `MediaHub.exe` в распакованной сборке); при необходимости так же перенесите `settings.json`,
`ext.json`, `archive_*.txt`, `browser_profile` и папку `ffmpeg`. Не перезаписывайте существующую
базу без резервной копии. Старые пути к скачанным файлам должны быть доступны на той же машине.
`ext.json` содержит секреты расширений — не публикуйте его. В исходной версии репозитория база находилась в `MediaHub/library.db`; после обновления
она может отсутствовать, поэтому заранее сохраните её копию. Данные создаются автоматически,
если их не перенести. `MEDIAHUB_DATA_DIR` при необходимости задаёт альтернативную папку данных.

## Доступность и уведомления

В «Настройки → Отображение и доступность» выбираются тема, размер интерфейса,
контраст и включение горячих клавиш. Выбор хранится в localStorage текущего браузера.
Справка по клавишам и журнал уведомлений доступны в боковой панели: нажмите `G`,
затем `L`, `I`, `D`, `G` или `S` для перехода в соответствующий раздел. Журнал
хранится только до закрытия/перезагрузки страницы, тосты исчезают через 8 секунд.
При блокировке localStorage настройки работают до перезагрузки, но не сохраняются.

## Игровая библиотека

В карточке игры можно добавить до 20 собственных тегов (через запятую, каждый до
40 символов). Они хранятся в базе отдельно от жанров сайта. Фильтр «Жанры и теги»
также включает движок; выбранные метки объединяются по принципу «и». Поиск учитывает
название, разработчика, жанры и теги. После сохранения тегов метки обновляются сразу.
При сканировании карточка с тегами или заметкой сохраняется, даже если папка игры исчезла;
явное удаление карточки удаляет её теги. Перед переносом или обновлением базы сделайте копию.

Размер определяется при сканировании GameSweep как сумма размеров доступных файлов
выбранной версии; 0 байт и неизвестный размер объединены в одном фильтре. У нескольких
версий размер относится к выбранной версии, а не ко всем версиям вместе. Сортировка и
размерный фильтр сохраняются в localStorage браузера. Игры с обнаруженным обновлением
всегда идут первыми, затем применяется выбранная сортировка. Поддерживаются даты выхода
в форматах, распознаваемых браузером, включая `ДД.ММ.ГГГГ`; неизвестные даты идут последними.

### Обложки игр

В настройке «Папка загрузок» выберите папку MediaHub: новые игровые обложки
сохраняются в её подпапку `covers` (по умолчанию `Downloads/MediaHub/covers`).
При сканировании установленной игры без доступной обложки приложение ищет файлы
`cover`, `folder` или `poster` с расширениями JPG, JPEG, PNG, WebP, GIF или AVIF
непосредственно в папке выбранной версии и сохраняет копию. Вложенные папки,
произвольные изображения и содержимое игровых архивов не просматриваются.

Старые доступные обложки остаются на прежнем пути; при смене папки загрузок они
автоматически не переносятся. Новые файлы получают уникальные имена и не перезаписывают
старые. Изображения ограничены 8 000 000 байтами и проверяются по сигнатуре, не полным
декодированием. Если обложка недоступна, остаётся заглушка; ошибки кэша записываются
в журнал приложения. Исходные файлы игры и старый кэш не удаляются. Автоматической
очистки неиспользуемых копий пока нет.

### Поиск скачанного обновления

Откройте карточку установленной игры. Кнопка «Обновить» открывает тему игры, если она
известна; выберите ссылку и скачайте архив вручную. При открытой карточке MediaHub
создаёт папку `Incoming_Downloads` внутри папки загрузок и показывает её путь. Сохраните
архив туда: поиск повторяется каждые 15 секунд, пока карточка открыта и вкладка видима;
его также можно запустить кнопкой «Обновить поиск».

Показываются только возможные совпадения по нормализованному имени для файлов ZIP, 7z,
RAR, TAR, TAR.GZ и TGZ непосредственно в этой папке; вложенные папки и ссылки не
просматриваются. Результат может ошибаться или не найти архив с иным именем. За один
поиск просматривается не более 5000 записей и выводится до 50 совпадений, с предупреждением
об ограничении. Содержимое архива и завершённость скачивания **не проверяются**. Папка
входящих загрузок и папка игр не должны пересекаться. Имя `Incoming_Downloads` зарезервировано:
GameSweep пропускает такие подпапки при сканировании; не выбирайте Incoming_Downloads
самой корневой папкой GameSweep.

Пока это только поиск: установки, распаковки, бэкапа и переноса сохранений нет, файлы игр
и архивы не изменяются. План безопасной реализации — `docs/smart-update-design.md`.

## Windows-сборка

После push откройте GitHub Actions → **Build Windows executable** → успешный запуск →
**Artifacts → MediaHub-Windows**. Распакуйте архив целиком в доступную для записи папку и
запустите `MediaHub.exe`; папка `_internal` обязательна. Это сборка `--onedir`, не одиночный
самодостаточный exe. FFmpeg, deno и браузеры Playwright не включены; установите их отдельно,
если они нужны. Настройки, база и профили создаются рядом с exe. Не запускайте из Program Files
без прав записи. Адреса расширений показывает вкладка настроек; при переносе сборки может
потребоваться повторная установка расширения.

## Проверка

```bat
py -3 -m unittest discover -s tests -v
py -3 -m compileall -q app.py core storage ui legacy tests
py -3 legacy/gamesweep.py --selftest
node --test tests/test_ui.mjs tests/test_quick_game.mjs tests/test_game_library.mjs tests/test_update_preview.mjs
```

Тесты используют временную базу и не скачивают контент из интернета. Windows workflow также запускает собранный EXE и проверяет ресурсы и локальное API.
Полная проверка загрузок,
расширений и Windows требует ручного тестирования. Память проекта: `AGENTS.md`, `MAP.md`, `STATE.md`.
