# MediaHub

Одно окно в браузере (http://127.0.0.1:8765): загрузка видео/аудио/сайтов/манги, библиотека, игры.

Запуск: `start.bat` (нужен Python 3; ffmpeg и deno кладите в папку `ffmpeg` рядом).

## Как устроено
Тёмный интерфейс, в центре обложки. Открывается библиотека; слева: «Добавить», «Библиотека», «Входящие», «Загрузки», «Игры», «Настройки».

* **Входящие и расширение для браузера.** Расширение (папка `extension`, Chrome и Edge) отправляет выбранные вкладки в приложение:
  текущую, отмеченные, группу или все вкладки окна. Приложение показывает предпросмотр: тип материала, что сделать
  (скачать, следить за обновлениями, только сохранить ссылку, пропустить), что уже есть в библиотеке и какие вкладки закроются.
  Ничего не скачивается, пока вы не подтвердите список. Вкладка закрывается только после успешной загрузки (за 5 секунд
  расширение предупреждает, можно отменить); при ошибке, отмене или неполной загрузке она остаётся открытой, и приложение
  пишет причину. Закрытую вкладку можно вернуть кнопкой в журнале «Входящих».
  Установка в Яндекс Браузере, Chrome, Edge, Brave (в Яндексе адрес `browser://extensions`): `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → папка `extension`.
  Установка в Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → файл `extension-firefox/manifest.json`.
  Временное дополнение пропадает после перезапуска Firefox. Чтобы оно осталось насовсем, подпишите архив `MediaHub-Firefox.zip`
  бесплатно на addons.mozilla.org (режим «Для собственного распространения») или используйте Firefox Developer Edition.
  Если уведомление о закрытии вкладки нельзя отменить кнопкой (Firefox), нажмите на само уведомление.
  Подключение подтверждается кнопкой «Разрешить» в приложении. Расширение видит только адрес и название отправленных вкладок;
  пароли, cookies, история и закладки не читаются.
* **Библиотека**: обложки с названием, категории со счётчиками, поиск (клавиша `/`), группировка по автору или теме,
  сортировка. Тип «Ссылки» — сохранённые источники без файлов (кнопка «Скачать» на карточке). Изменить и удалить: при наведении.
  Манга открывается во встроенной читалке и запоминает место.
* **Добавить**: ссылки и тип (видео, аудио, манга, сайт). «Дополнительно»: выбор страниц сайта, диапазон глав, расписание,
  список ссылок из файла. «Проверить размер» показывает, сколько займёт загрузка и сколько места останется.
* **Загрузки**: ход, скорость, оставшееся время, отмена; внизу экрана полоса загрузки.
* **Манга**: по умолчанию загрузка идёт **в вашем браузере** через расширение (Яндекс Браузер, Firefox, Edge, Chrome): на время загрузки
  оно открывает небольшое окно сайта под вашим входом, берёт список глав и адреса страниц (режимы «Лента» и «По страницам»),
  а MediaHub скачивает картинки параллельно. Окно загрузки не закрывайте, в конце оно закрывается само. Готовые главы
  при повторном запуске пропускаются, ошибки пишутся в `download.log`. Запасной вариант («Отдельным окном» в настройках):
  собственный браузер MediaHub через Playwright; для него можно взять cookie из Firefox (работает всегда) или из Edge/Chrome
  (они шифруют cookie и блокируют базу, пока открыты, поэтому нужно закрыть браузер).
* **Игры** (вкладка «Игры», две части):
  **Библиотека** в стиле Playnite: обложки с названием, в правом нижнем углу кружок (✓ скачано, пустой — не скачано), плашка «Обновление».
  Щелчок по карточке открывает слева панель: версия у вас и последняя, разработчик, движок, система, язык, дата выхода, размер, жанры
  (щелчок по жанру включает фильтр), описание, ссылки на скачивание, «Следить за новыми версиями», заметка. Сортировка (название, недавно
  добавленные, с обновлением, размер, дата выхода), фильтры «Скачано / Не скачано / Есть обновление» и по жанрам.
  Карточка создаётся из вкладки с темой игры: во «Входящих» выберите «Добавить игру в библиотеку» (или вставьте ссылку на тему в самой
  вкладке). Расширение читает страницу в вашем браузере под вашим входом; MediaHub разбирает название, версию, жанры, обложку и ссылки.
  Установленные игры из папки (настройки) сливаются с карточками по названию. «Проверить обновления» (и расписание в настройках)
  открывает темы по одной с паузой и сравнивает версии. **Версии и чистка**: GameSweep (старые версии, Корзина; двойной щелчок по строке
  открывает папку; любую версию можно выбрать, актуальную только с подтверждением). Файлы игр из библиотеки не удаляются и не переносятся.
* **Настройки** (сохраняются сами): папка, качество видео, формат звука, субтитры, обложки, число загрузок,
  лимит скорости, параметры сайтов, окно браузера для манги, cookie, папка игр, подключённые расширения.

## Скорость
Плейлисты и каналы качаются несколькими видео сразу; манга: страницы главы параллельно, пока браузер листает
следующую (картинки и реклама в самом браузере отключены); ресурсы сайтов качаются в 8 потоков.

## Безопасность
Сервер слушает только 127.0.0.1; проверяется заголовок Host (защита от DNS-rebinding), управляющие запросы
принимаются только из окна MediaHub (заголовок X-MH + проверка Origin); GameSweep закрыт собственным токеном.

Расширение подключается только после вашего согласия в приложении; доступ идёт по секретному токену, который хранится
в `ext.json` рядом с программой (не копируйте этот файл другим людям).
